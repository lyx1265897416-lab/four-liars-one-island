# 导演层 Sonnet 5.5 vs Opus 5.5（Kimi K3.1 Pro 作参照）｜2026-11-05

同一组 5 轮输入（Jasper 线：我选 Jasper → 嗯 → 点 A → 去泳池找 Ravi 读 Jasper → 点 A），同一份 V3.11 编剧/导演 PE。Sonnet、Opus 经本机 Claude Code 调用（OpenRouter 仍 403），耗时含命令行开销，比直连 API 慢。

| | Sonnet 5.5 | Opus 5.5 | Kimi K3.1 Pro |
|---|---|---|---|
| 每轮耗时（5 轮） | 100 / 63 / 163 / 66 / 93 秒 | 100 / 46 / 115 / 96 / 56 秒 | 56 / 87 / 74 / 38 / 193 秒 |
| 打回重写 | 1 轮 | 3 轮 | 2 轮 |
| 校验后剩下的问题 | 1–4 处（多为道具没写进场景） | 1–3 处 | 1–2 处 |
| 每轮台词 | 6–9 句 | 8–9 句 | 8–10 句 |
| 等价费用（Claude Code 报的） | 5 轮约 0.78 美元 | 5 轮约 1.30 美元 | — |

**台词和人设（同一处情节）**
- 第 1 轮 Jasper 装骗子：Sonnet「Bed's yours. I've slept on worse. Boats, mostly.」→「Yes. I owe people money. Still want me?」；Opus「Bold. You don't even know my last name.」→「Before you ask—yes. I'm one of the four.」「I owe people. Half that million clears it.」；Kimi「Bad odds. Good taste.」→「Yes.」「Still want me?」
- 第 3 轮她赢了夺旗赛：Sonnet 直接揭底「No debt. I wanted to see who stays.」（第 3 轮就揭开装骗子，太早）；Opus 只给一半「One man. He overpaid me last year.」（暗指公司被收购，钩子留着），挖苦 Sloane「Look at that. She's walking. A miracle.」
- 第 4 轮去找 Ravi：Opus 的 Jasper「Go. Ten bucks says he calls me broke.」「Tell Ravi I don't tip.」，Ravi「Rope calluses. Broke guys don't sail.」；Sonnet 的 Ravi「Liars brag. He shrinks himself.」
- 第 5 轮：Opus 让 Ravi 读出「Wes touches his collar. He's on assignment.」（接上 Wes 的任务卡），Jasper 加注「Two real ones left. Find one, I'll talk.」；Sonnet 让 Jasper 提交换「Tell me Ravi's price. I'll tell you who Ethan meant.」
- 表情：三个都按新规则写了（皱眉、下颌绷紧、愣住、不笑），Kimi 有几拍空动作（“胜负已定。”）。

**问题**
- Opus：两处说话人标错（她自己在吧台说的话标成了“画外:Wes”）。
- Sonnet：第 3 轮就揭开 Jasper 装骗子，反转用得太快；第 5 轮一段里放了 4 个配角。
- Kimi：台词平，人物辨识度低。

**结论**：要“反转多、hook 多、跌宕”，Opus 明显更好——台词更有性格，秘密收放更稳，能主动把人物卡里的伏笔（任务卡、船、茧）串起来；Sonnet 稳、便宜约四成，但反转揭得急。速度在命令行下两者差不多；换成官方 API 直连后 Sonnet 会比 Opus 快。
